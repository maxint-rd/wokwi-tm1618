### Live demo

Go to the [live demo on Wokwi](https://wokwi.com/projects/452129958367862785) for a working copy of this example.

### Installation
To install this example as your own project you can use the "Save a copy" command in the left-top of the Wokwi interface.
In the library manager you can see it uses the latest release of the [TM16xx Arduino Library](https://www.arduinolibraries.info/libraries/tm16xx-le-ds-and-buttons).
For an even more recent version, you can get the code from the [TM16xx Library repository](https://github.com/maxint-rd/TM16xx) .

A downloaded zip file of this example is stored [here](https://github.com/maxint-rd/wokwi-tm1618/examples/TM1618_custom_chip_setSegments/TM1618_custom_chip_setSegments.zip).
